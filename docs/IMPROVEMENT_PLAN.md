# Android 客户端改进清单

更新时间：2026-08-20

服务端基线：青龙最新版本，运行镜像已包含安全修复 `6bec52d`

## P0：下一阶段必须优先处理

### 1. 客户端凭证加密

- [x] 将 Token、记住的密码和 mTLS 证书密码从明文 Preferences DataStore
  迁移到 Android Keystore 支持的加密存储。
- [x] 设计向后兼容的一次性迁移；迁移成功后删除旧键值。
- [x] 日志、崩溃信息与错误提示不得包含 Token、密码或证书密码。

验收：导出的应用数据、调试日志与普通文件读取均无法获得明文凭证；升级旧版本
后仍能登录或明确要求重新登录。

### 2. 移除同步阻塞的会话读取

- [x] 删除 `SessionManager` 属性中的 `runBlocking`。
- [x] 为同步的 OkHttp 拦截器提供生命周期明确的内存会话快照，登录、退出和切换账号
  必须原子更新。
- [x] Retrofit 服务不得在单例 Repository 创建时固定旧 Host；切换服务器后所有请求
  必须使用新 Host 和对应证书。

验收：严格模式下无 DataStore 主线程阻塞；连续切换两个服务器后，请求、Token 和
mTLS 配置不会串用。

### 3. 明文 HTTP 改为显式授权

- [x] 默认只接受 HTTPS。
- [x] 若需要局域网 HTTP，在服务器配置中增加醒目的“允许不安全 HTTP”开关，按账号
  保存且默认关闭。
- [x] 已评估动态网络安全策略：Android Manifest 无法为运行时任意 LAN Host
  生成按账号例外，因此保留传输能力，并在应用层按账号默认拒绝 HTTP。

验收：新建 HTTP 服务器默认被拒绝；用户明确授权后仅该服务器可用，切换服务器不会
继承授权。

### 4. 私有 CA 支持

- [x] 保持系统证书与主机名校验，新增可选的私有 CA 导入，不恢复 Trust-All。
- [x] 客户端身份文件（PKCS#12）和服务端信任锚必须分开配置与提示。
- [ ] 增加过期、域名不匹配、错误 CA 和正确私有 CA 的连接测试。

验收：公开 CA、正确私有 CA 和 mTLS 正常连接；任一错误证书或错误主机名均失败。

## 实施约束

- 不通过修改 Splash、Activity 背景或图标来掩盖启动/退出视觉问题。
- 不恢复 Trust-All、全局主机名跳过或 Release BODY 日志。
- 不把备份发送到 Cloudflare Worker、R2 或其他第三方服务，除非未来有独立需求、
  威胁模型和用户明确授权。
- 破坏性恢复必须保留二次确认、应急命令提示和测试实例验收。
- 每完成一项，勾选本文件并在对应 PR 中附上测试证据。
